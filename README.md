BrightPath Futures — Charity Platform Prototype

BrightPath Futures is a fictional Northbridge charity established in 2018 dedicated to helping children and young people build confidence, practical skills, and stronger futures. This prototype delivers a web application uniting three core services: Membership, Sponsorship, and Fundraising Events.   

🚀 Core FeaturesHome & Impact: 
Live impact stats (1,240 participants, 86% confidence boost) and service navigation.   
Charity Membership: Tiered subscription plans (Friend £3/mo, Champion £8/mo, Partner £15/mo) with validation and confirmation steps.   Sponsorship: One-off or recurring contributions (£10–£150 fixed tiers or £2–£10,000 custom options) with test-mode integration.   Fundraising Events: Searchable schedule (Northbridge Fun Run, Code for Change Day, etc.) with registration and accessibility request options.

🔒 Key Security & Data Principles
Stripe Test Mode Only: Uses Sandbox mode exclusively; no live payment keys or real card processing allowed.   
Mandatory Notice: Payment screens display "Stripe test mode — no real payment has been taken."   
Data Protection: Strictly fake data used for testing; sensitive credentials or card data are never stored on app servers.   ✅ Acceptance Criteria
Functional execution of Membership, Sponsorship, and Event registration flows.   
Accessible across screen sizes with keyboard navigation and plain language.   
Input validation, error handling, and submission feedback on all forms.   
Clear separation between prototype test mode and real-world transactions.
